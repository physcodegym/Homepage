Benchmarking Coding Agents for
Physically Verifiable 4D Reconstruction

PaperCodeDatasetEvaluation

Can coding agents reconstruct the physics behind a video?

We introduce PhysCodeGym, a benchmark of 156 video-to-program tasks spanning rigid-body, liquid, deformable, and wind-driven motion. Given a reference video, agents write, execute, and refine Blender programs to reconstruct the scene and its dynamics. We evaluate visual fidelity and physical validity through six metrics, combining rendered-video assessment with program inspection, native-scene measurements, and counterfactual tests.

Why physical verification matters

Matching objects and events can still hide a physical defect.

In this GPT-6-Astra reconstruction, object and event scores are both 1.0, yet potential energy reaches 9.44 mJ after release—above the estimated initial-energy upper bound of 4.97 mJ.

Benchmark

PhysCodeGym contains 156 video-to-program tasks across rigid-body, liquid, deformable, and wind-driven motion. Each reference is eight seconds long at 30 FPS. Agents submit a runnable Blender program and its native scene; evaluation measures both the rendered video and the mechanisms that produce it.

The public release includes task-specific object, event, and physical-validity rubrics. 43 tasks include counterfactual checks within physical validity.

Coverage and provisional physical scores ＋

Each configuration targets 156 tasks. Missing artifacts receive zero on every metric. Repeated tasks use the latest run with a rendered artifact, not the highest-scoring run.

Provisional validity uses lower endpoints of rubric-score intervals. Technical gaps for existing artifacts are omitted; registered missing-artifact zeros remain. S_phys is computed per task, then averaged over the same available subset as validity. It cannot be reconstructed by averaging the differently covered Event, Motion, and Validity columns.

Model-level S_tot averages the displayed S_vis and S_phys. Equivalence to a six-metric mean requires identical averaging sets for all six metrics.

FAQ

What does the agent reconstruct from a video? ＋

The agent writes an executable Blender program that builds the objects, materials, camera, and lighting, and sets physical properties, initial conditions, constraints, and forces. The submission includes the program and the native scene it generates. This makes the reconstruction runnable, inspectable, and available for re-simulation under changed conditions.

How are physical parameters determined from a video? ＋

The reference scene’s source program and physical parameters are not provided. The agent chooses parameters from the visible appearance, motion, and interactions, then runs the scene, inspects previews, and revises its program; the benchmark does not prescribe a single parameter-estimation algorithm.

A single video does not uniquely identify every physical parameter. Equivalent implementations are accepted when they reproduce the observations and satisfy the task’s physical requirements; exact hidden geometry and true parameter values are not required.

How is motion generated in the reconstructed scene? ＋

Core-object motion must arise from physics solvers, forces, constraints, and initial conditions. For example, dominoes should fall through successive collisions, rather than following a separately scripted falling trajectory for each piece. Explicitly modeled external actuators are allowed, provided that the objects they act on respond through physical interaction. Scripted core-object trajectories and forces with no counterpart in the reference, such as an attractor steering a ball along a prescribed path, do not satisfy this requirement.

How do you check whether the reconstruction is physically valid? ＋

Each task has a manually annotated physical rubric specifying the permitted setup, actuation, and mechanisms to verify. A verification agent reads the program and native scene, identifies the relevant objects, and writes and executes Blender/Python probes to inspect how motion is produced and measure contact, support, and object states over time. Each judgment is supported by source references or measured evidence; rendered appearance alone is insufficient.

What happens when the physical conditions are changed? ＋

For tasks with counterfactual checks, the verifier copies the scene, changes a specified force, contact relation, or initial condition, and re-simulates it against the unchanged baseline. For example, if a ball moves a target through collision, removing their contact while preserving the ball’s incoming motion should eliminate the target’s impact-induced response. The verifier confirms that the intervention takes effect and uses control scenes to check the measurement before judging whether the required physical dependence holds.

Can a reconstruction look correct but still fail the physics checks? ＋

Yes. Scripted trajectories, hidden supports, or incorrect collision geometry can reproduce the reference frames while producing an invalid physical response. Even when object and event scores are high, program inspection and scene measurements can reveal these defects. Conversely, a scene with a valid physical mechanism may still miss the reference event, so visual fidelity, event reconstruction, and physical validity are assessed separately.

How is reconstruction quality measured? ＋

Visual quality covers frame structure, perceptual similarity, and object correctness. Physical quality covers events, motion patterns, and physical validity. We report the component metrics alongside visual, physical, and overall scores to distinguish appearance mismatches from mechanism failures.

How scores are combined

S_vis = (SSIM + LPIPS similarity + Object) / 3
S_phys = (Event + Motion + Validity) / 3
S_tot = (S_vis + S_phys) / 2

These formulas define the per-task aggregates. Model-level scores follow the coverage and provisional-score rules described below the leaderboard.

Events use three independent judgments and a majority vote per item. Failure of a task-defining key event caps the event score at zero. Counterfactual checks are criteria within physical validity, not a seventh metric.
